1. What is/are the parent class/es of the Programmer class in the video?
    The parent classes present in the video are the Employee and Customer class which both come from the Person class making the Person class the grandparent. 

2. If you were to add a new role called Intern, where would you place it in the inheritance
hierarchy? Why?
    If I were to add a new role called Intern, I would place it as a child class with its parent class being one of the child classes of the Employee class. I made it as a child class of one of the employees because an intern could have an internship for manager, programmer, cleaner and many other jobs that isn't present in the example.
